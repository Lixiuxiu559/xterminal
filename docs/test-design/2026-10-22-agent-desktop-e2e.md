# Agent桌面端到端验收设计

依据：PRD固定引擎、对话/审批/提问/停止、关窗保活与重启恢复要求；架构规定不自动重发、原生上下文明确恢复。复用Electron smoke设施，不新增测试框架。

测试分两层：协议夹具经过真实CLI子进程、生产适配器、utility Host、SQLite、preload和React；真实模型层使用本机官方登录、临时项目、固定短标记且禁止工具。两层结果分别记录，夹具不证明真实供应商行为。

| 编号 | 操作 | 断言与不得发生的副作用 |
| --- | --- | --- |
| E01 | 在新建弹窗依次选择Claude/Codex、填写名称并创建 | 页面引擎一致；不能在已有会话切换；真实Host记录固定engine |
| E02 | 原生文本输入+发送按钮发送含中文/emoji标记 | UI用户消息/助手最终消息各一条；partial被final覆写，不追加重复；SQLite重启后相同 |
| E03 | 权限夹具分别点击允许本次/拒绝 | 只回答当前原生ID一次；无永久规则；显示完成；未知交互不能默认允许 |
| E04 | 问题夹具选择单选/多选并输入自由答案 | 提交前须完整；原生回答字段与选择吻合；卡片移除后不能重复提交 |
| E05 | 运行等待夹具时点击停止 | 等终态确认后才可再发；不把interrupt受理等同结束；该轮记录interrupted |
| E06 | 输入草稿、切换会话再返回 | 草稿还在本窗口；不自动发送 |
| E07 | 活跃等待轮次期间关闭全部窗口再恢复 | 同一run仍在；当前权限/停止入口恢复；无新turn/start |
| E08 | 正常退出并重启、打开原会话 | 历史文本和engine保留；没有自动模型调用；无控制权先明确接管 |
| E09 | 重启后明确发送续聊 | 适配器用保存的原生上下文ID；真实模型仅据前文恢复随机标记，提示中不再包含该标记 |
| E10 | 两引擎真实短请求 | UI→preload→Host→官方CLI→UI最终结果；无工具/审批、错误明确失败；不修改凭据/模型全局设置 |

真实模型用例会消耗本机额度，单独显式命令；默认测试不调用模型。截图只拍临时项目，不保存账户/认证内容。崩溃恢复另由强制终止Host/应用验收承接，不把正常重启E08算作崩溃验收。
