# XTerminal 设计规范

版本：v0.3\
更新日期：2026-10-22\
适用范围：桌面应用原型与手机浏览器原型\
关联需求：[产品需求文档](PRD.md)

## 1. 设计目标

让用户快速找到正在处理的任务，理解当前执行状态，并能在电脑和手机上继续同一个会话。

借鉴成熟产品的信息组织方式，建立自己的视觉语言：暖白的工作画布、墨绿的主要操作、低干扰的项目导航，以及独立的石墨色终端。

## 2. 参考与取舍

| 参考产品 | 借鉴点 | 本产品的处理方式 |
| --- | --- | --- |
| [DeepSeek Harness](https://deepseek.com/harness/) | 工作区下组织会话 | 本地目录作为项目入口，三个引擎共用会话导航 |
| [ChatGPT](https://learn.chatgpt.com/docs/projects) | 易读的对话与项目组织 | 以任务为会话单位，阅读宽度受控，导航可以收起 |
| [Claude Code Desktop](https://code.claude.com/docs/en/desktop#arrange-your-workspace) | 按需打开辅助面板 | 目录、运行位置和状态放在会话详情，不常驻多条状态栏 |

不复制参考产品的品牌色、图标或整个外观。三种引擎的差异通过名称、图形和必要的交互表现，不能只依赖颜色。

## 3. 视觉语言

### 3.1 色彩

浅色为默认主题，深色可在设置中切换，偏好保存在当前浏览器。Shell 始终使用独立深色画布。

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 工作画布 | `#FAFBF8` | `#19211D` | 主工作区 |
| 导航背景 | `#F0F2ED` | `#131A16` | 项目与会话 |
| 内容表面 | `#FFFFFF` | `#222D26` | 输入框、弹窗和工具记录 |
| 正文 | `#26362D` | `#E5ECE3` | 标题与主要文字 |
| 次级正文 | `#4B5C51` | `#C0CEBF` | 回复与辅助说明 |
| 辅助文字 | `#5F6E64` | `#A2B3A1` | 标签与提示 |
| 主要操作 | `#285A43` | `#BFD5B7` | 创建、发送、确认 |
| 待确认 | `#835C20` | `#E8C581` | 需要用户处理的操作 |
| 终端背景 | `#15221C` | `#15221C` | Shell 工作区 |

正常连接弱化显示；待确认、断线等需要行动的状态采用文字、图标和语义色共同表达。

### 3.2 字体与尺寸

- 使用系统无衬线字体；目录、命令和终端使用系统等宽字体，无需下载字体。
- 桌面与手机回复正文 15px，约 1.95 行高；手机输入框 16px，减少移动浏览器聚焦放大。
- 桌面对话最大阅读宽度约 780px；终端使用完整工作区宽度。
- 次级说明采用 10–13px，不用它承载主要任务、操作或必要信息。
- 超长会话名在导航与标题栏截断，完整名称可在详情中查看和修改。

### 3.3 形状与图标

- 4px 为主要间距基数；输入区圆角 12–13px，操作控件 7–9px。
- 弹窗圆角 18px；手机创建会话使用底部弹层。
- 使用本地 SVG 线性图标，统一线宽与尺寸；图标按钮提供可访问名称。
- 自有标记以小写 x 与终端光标组合，产品名仍为暂定代号。
- 当前会话通过表面背景、文字字重和左侧色标共同识别。

## 4. 信息结构

桌面：项目与会话导航 → 主工作区 → 按需打开的会话详情。

- 导航：新建、搜索、项目与会话、手机连接、个人入口与设置。
- 标题栏：当前项目、会话名称、固定引擎、必要状态、详情入口。
- Agent 主区：用户消息、回复、折叠的工具记录、执行状态。
- 输入区：任务输入与发送；待授权时替换为固定确认卡片。
- Shell 主区：进程信息、可滚动的输出与命令输入、固定控制区。
- 详情：项目、工作目录、固定引擎、状态、执行位置、手机连接、重命名。

不把当前引擎设计为下拉选择器，避免用户误认为已有会话可以切换引擎。

## 5. 响应式规则

| 可用宽度 | 布局 |
| --- | --- |
| 大于 1160px | 282px 导航；主工作区；可选 294px 详情面板 |
| 761–1160px | 252px 导航；详情以覆盖面板打开，避免压缩对话 |
| 不大于 760px | 导航收起为抽屉；单会话工作区；详情使用全宽页面 |

布局按原型容器宽度响应，因此桌面中的手机预览与独立手机页面使用同一规则。

当视口高度不大于 650px 时，导航改为整体滚动，避免会话列表被顶部导航和底部设置挤压。

手机标题栏分两层：第一层会话名称与导航、详情按钮；第二层明确显示引擎名称和执行状态。手机优先保证核心操作，不常驻目录路径和桌面快捷键提示。

## 6. 交互规则

- 创建前选择引擎，创建后固定；已有项目可以分别拥有 Agent 和 Shell 会话。
- 搜索支持会话名、项目名及引擎名称；无结果时解释可搜索内容。
- 项目可以折叠；创建会话后自动展开所属项目并清空搜索条件。
- 空消息不允许发送，输入时自动调整输入框高度。
- 桌面 Enter 发送，Shift + Enter 换行；手机 Enter 换行，通过发送按钮提交。
- 执行中显示停止按钮；停止请求和完成停止分别反馈。
- 权限确认固定在底部，展示操作、命令、执行位置以及允许、拒绝入口。
- 断线时禁用远端输入和权限提交，保留 Agent 与 Shell 草稿；重连后恢复。
- Shell 的 Ctrl+C 中断当前命令，保留 Shell 会话；底部控制区独立于输出滚动。
- 手机的关键控件触摸区域至少约 44px，命令输入有独立执行按钮。
- 导航抽屉支持遮罩关闭、Escape 和键盘焦点约束；弹窗使用原生 dialog。
- 手机详情打开时限制背景内容操作；减少动画偏好生效时关闭非必要动效。
- 页面监听可视视口变化，适配软键盘导致的可用高度变化；真机输入法与 Safari 行为仍需后续验证。

## 7. 原型范围与验证

本轮验证以语法检查、真实浏览器交互和不同视口截图为准。验收覆盖默认会话、空状态、搜索、项目折叠、三引擎创建、授权、停止、断线草稿、Shell 输入与中断、浅深主题。

当前模拟会话、连接与命令执行，未接入真实引擎。浏览器模拟尺寸不能替代 iOS / Android 真机测试。

本轮为原型样式与交互调整，不引入额外测试框架；未运行复杂度审计与突变测试。可比较的 Git 基线与测试工具链尚未建立，因此不宣称完成这些审计。
