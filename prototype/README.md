# XTerminal 交互原型

当前版本：v0.3。设计规范见 [DESIGN.md](../docs/DESIGN.md)，产品边界见 [PRD.md](../docs/PRD.md)。

独立 HTML / CSS / JavaScript，无构建或网络资源依赖。可直接打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/?v=3`。`?mobile=1` 可以在桌面中查看窄屏布局。

## 风格与布局

- 暖白工作画布、墨绿操作、独立石墨终端；支持浅深主题。
- 统一 SVG 图标、色彩变量、间距和状态反馈。
- 桌面按项目组织会话，支持搜索、折叠和收起导航；详情按需打开。
- 三种引擎共享导航，Claude Code / Codex 使用对话，Shell 使用终端。
- 手机使用两层标题、抽屉导航、全宽详情和创建底部弹层；触屏关键操作约 44px。
- 手机 Enter 换行，点击发送；桌面 Enter 发送，Shift + Enter 换行。

## 可以体验的流程

1. 默认会话查看消息、展开执行记录，或点击回复中的建议开始输入。
2. 搜索会话标题、项目或引擎名称，折叠和展开项目。
3. 新建会话，选择 Claude Code、Codex、Shell；创建后引擎不可切换。
4. 新建 Agent 会话展示空状态，可使用快捷建议填入消息。
5. 进入“检查项目依赖”，处理固定在底部的允许 / 拒绝操作。
6. 发送消息，观察执行中状态，停止或等待模拟结果。
7. 进入 Shell，尝试 `pwd`、`ls`、`cd`、`echo`、`pnpm dev`，通过按钮或 Ctrl+C 中断。
8. 打开会话详情，查看工作目录、引擎、状态，或重命名。
9. 点击“连接手机”，体验分步引导、模拟配对、撤销授权及手机预览。
10. 在“设置与外观”切换浅深主题，或模拟断线；Agent 与 Shell 的输入草稿保留，重连后继续。

## 本轮验证

- `node --check prototype/app.js`、`node --check prototype/icons.js`。
- 浏览器验证搜索、无结果、项目折叠、详情与重命名、三引擎创建、授权、停止与回复、设备配对和撤销、主题、断线草稿。
- 检查 320 / 390 / 768 / 1024 / 1440px 布局，以及较低可用高度；另保存浅深主题和不同页面的实际截图。
- 视觉与尺寸检查使用浏览器模拟，尚未进行 iOS / Android 真机或真实软键盘测试。

## 边界

不调用真实引擎、不执行真实命令、不提供真实内网连接或设备授权。示例地址与配对码不可用于实际连接。

会话只存在于当前页面内存，刷新重置；仅主题偏好保存在浏览器。第一版真实的设备配对方案、Shell 程序兼容、后台生命周期等仍以 PRD 的待确认事项为准。

本轮没有引入额外测试框架、复杂度或突变测试工具；原型目录尚无可用 Git 评审基线，不宣称完成相关审计。
